# 🚀 RankBoost AI

An AI-powered SEO analysis platform built using the MERN stack (React, Node.js, Express, MySQL).  
RankBoost AI helps users analyze website SEO performance, generate optimization suggestions, and track SEO reports through a modern dashboard.

---

# 🌟 Features

## 🔐 Authentication System
- User Registration
- User Login
- JWT Authentication
- Protected Routes

## 📊 SEO Analyzer
- Website SEO score analysis
- Meta title analysis
- Meta description analysis
- H1 & H2 heading analysis
- Image alt text analysis
- Internal link analysis
- Word count analysis

## 📈 Analytics Dashboard
- SEO report history
- SEO score charts
- Professional dashboard UI
- Responsive layout

## 💾 Database Integration
- MySQL database
- SEO report storage
- User management system
